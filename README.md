# Java Media Player and Playlist

This is my lab assignment for the Data Structures and Object-Oriented Programming course. It's a simple console-based media player application written in Java.

The main goal of this project was to practice core OOP concepts like inheritance, polymorphism, and exception handling. The program allows users to create playlists, add different media types (songs and podcasts), and save or load these playlists using text files.

**What it does:**
* Provides an interactive command-line menu.
* Manages `Song` and `PodcastEpisode` objects using a common `MediaItem` parent class.
* Handles File I/O operations (saving data to a `.txt` file with `|` separators).
* Uses custom exceptions (`MediaItemNotFoundException`) for basic error handling.

**How to run:**
Simply clone the repository and run the `MediaPlayer_Playlist.java` file. It was developed using NetBeans, but it will work fine on any Java IDE.
